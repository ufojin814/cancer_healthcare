# OncoPilot · 本地临床试验匹配工具（个人自用）

## 定位

个人自用的公开临床试验信息检索与匹配原型：上传/粘贴病历 → 抽取患者画像 → 与本地试验库比对 → 输出候选试验清单、匹配理由、存疑项与时效分级，支持导出 HTML / CSV 报告。

**本工具不构成诊断、治疗建议或用药推荐；匹配结果不代表入组资格，是否符合条件以研究团队筛查与书面知情同意为准，诊疗决策以主治肿瘤科医生意见为首要依据。**

## 合规边界（个人自用）

- 仅服务本人/家庭事务场景，不对外公开、不收费、不向其他患者提供结果；一旦扩大为公开服务，需另行评估医疗机构资质、医疗器械分类、个人信息保护、生成式 AI 备案与数据出境等要求。
- 病历属敏感个人信息：上传前删除姓名、身份证号、电话等身份字段；本工具默认本地存储，不调用境外大模型；LLM 抽取适配器预留接口，接入境内服务前需单独评估。
- 基因检测报告/突变信息属人类遗传资源信息，不要上传境外服务或境外服务器。

## 安装与启动

```powershell
# 安装依赖
python -m pip install -r requirements.txt

# 启动本地服务（浏览器访问 http://127.0.0.1:8000）
python run.py
```

命令行冒烟测试（小批量拉取样例癌种并跑通全链路）：

```powershell
python -m oncopilot.smoke_test
```

## 使用流程

1. **同步数据**：页面输入可选癌种/关键词，点击"同步最新数据"。ClinicalTrials.gov 按最近发布日期倒序拉取，与本地快照比对，仅落库新增或有变更的记录；页面显示本地库条数与源库数据批次时间戳。
2. **录入病历**：上传 PDF/TXT 或粘贴病历文本（诊断、病理、分期、基因检测、既往治疗线数与用药、化验、ECOG、城市）。
3. **查看候选**：结果按"可能匹配 / 存疑待核 / 不符合"排序，每条标注时效分级（绿：在招且近期更新；黄：需向研究中心核实；红：当前不可申请）、命中理由与存疑/风险提示。
4. **导出报告**：HTML 或 CSV，含登记号、链接、状态、期别、命中标签、理由与存疑项。
5. **人工核对**：国内 CDE、ChiCTR、CTIS 入口由页面生成检索链接，需手动检索并以研究中心答复为准。

## 数据源与时效机制

| 数据源 | 获取方式 | 时效 |
|---|---|---|
| ClinicalTrials.gov | API v2 公开接口，客户端增量比对 | 源库工作日每日刷新；以 `/api/v2/version` 的 dataTimestamp 校验批次 |
| CDE 药物临床试验登记平台 | 无开放 API，生成检索链接人工核对 | 以详情页公示为准 |
| ChiCTR | 无开放 API，生成检索链接人工核对 | 月度批次更新 |
| EU CTR / CTIS | 生成检索链接人工核对 | 以门户公示为准 |

## 匹配逻辑

- **硬筛**：年龄区间、性别限定；不满足直接判不符合。
- **召回与评分**：癌种标签交集加分、靶点/标志物交集加分、城市就近加分、在招状态加分；既往已用同名/同类药物降权并提示耐药与洗脱要求；围手术期/辅助阶段试验与晚期转移性病情冲突时降权提示。
- **时效分级**：依据试验状态与最近发布日期计算新鲜度；超期未更新、受邀入组、状态未知归入黄色待核。

## 已知局限（首期原型）

1. 规则与同义词表覆盖常见实体瘤与热门靶点，罕见癌种/靶点需人工补充别名；病历 OCR 与非结构化文本抽取准确率有限，画像必须人工核对。
2. 入排标准为自由文本，阈值、既往线数、合并症等细粒度条件尚未全部结构化，存在误配/漏配；候选清单需逐条阅读入排标准并联系研究中心核实。
3. 本地库当前按关键词小批量拉取；全量同步需评估分页耗时与本地存储。
4. LLM 结构化抽取接口预留但未接入；当前为规则模板抽取。
5. 未接入医院私有 HIS、药企私有管线与真实世界结局数据；这些数据受合同与隐私约束，不在个人自用范围内。

## 后续可增强方向

- 扩充癌种/靶点/药物同义词表与中文医学术语映射；
- 接入境内大模型做病历结构化抽取（脱敏后调用，病历不出境）；
- 向量召回 + 规则重排，提升相关性；
- 试验方案版本比对、入排阈值结构化解析；
- 与 CDE/ChiCTR 合规授权后定向采集。
